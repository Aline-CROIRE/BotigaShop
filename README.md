# Botiga Multi-Vendor Blog Frontend

This is the frontend for the blog page of the Botiga Multi-Vendor e-commerce platform, built using React.

## Features

- Responsive design for optimal viewing on various devices
- Pagination for blog posts
- Ability to filter blog posts by category
- Search functionality to find specific blog posts
- Individual blog post pages with related posts
- Integration with the Botiga Multi-Vendor backend API

## Technologies Used

- React
- React Router
- Axios (for API calls)
- Styled Components (for styling)
- Moment.js (for date formatting)

### Prerequisites

- Access to the Botiga Multi-Vendor backend API
